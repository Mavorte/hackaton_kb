Datová vrstva

  • Tabulky: ares_raw, uw_documents, uw_attributes, uw_rule_results, uw_vectors, uw_feedback
  • Vektory: první strana dokumentu a shrnutí případu; klíč dokument + model, vektory modelů se nemíchají
  • Sémantická vrstva (YAML): metriky a dimenze → bezpečné SQL (whitelist, parametry)
  • MCP server (14 nástrojů): podobné dokumenty, příklady, precedenty případů, statistika pravidel, zpětná vazba
  • Úložiště: SQLite (vývoj) → PostgreSQL + pgvector (škálování)

Tech stack

  • Python 3.11, pydantic, YAML konfigurace
  • boto3 · Bedrock Converse (obrazové bloky)
  • PyMuPDF, Pillow, reportlab (syntetická data)
  • SQLAlchemy 2, numpy (kNN)
  • FastAPI, Streamlit, MCP SDK (stdio)
  • pytest (45+ testů), evaluace proti truth.json

Odhad čísel (ne měření)

  • Náklad na případ: asi 0,05–0,20 USD proti 0,43 USD v PoV (GPT-5.2 + Azure OCR, únor 2026). Úspora z kaskády Haiku → Sonnet, cache a rychlé cesty z báze.
  • Přesnost pravidel: PoV 97,2 % (140/144, interval 93–99 %). Cíl 98–99,5 %: vizuální čtení odstraní chyby OCR, segmentace řeší dva dokumenty v jednom skenu.
  • Rozdíl pod ~3 p. b. se na 144 pravidlech nedá prokázat, proto vlastní sady eval_a–d (60 případů, 660 pravidel; rozliší rozdíl kolem 1 p. b.).

Stav a rizika

  • Pipeline, báze, pravidla, MCP a UI běží a jsou testované v mock režimu.
  • Vizuální cesta je ověřená jen na falešném modelu; účet zatím neumožňuje volání Bedrocku.
  • Textract není v eu-north-1, proto vizuální model místo OCR.
  • Mock embeddingy jsou lexikální; práh báze se kalibruje až na Titanu.

Responsible AI a compliance

  • U každé hodnoty strana a citace; model bez důkazu hodnotu nevrací.
  • Strojové štítky nehlasují, dokud je člověk nepotvrdí.
  • Lidské schválení u každého nálezu; model rozhoduje jen hraniční shody.
  • EU region a profily eu.*; jen syntetická data, žádné reálné osobní údaje.
  • MCP smí číst jen složky pod povoleným kořenem.
